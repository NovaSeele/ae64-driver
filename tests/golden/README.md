Golden outgoing HID frame logs for AE64 seeds (`max`, `pro`, `pro-xinput`), recorded on the pre-MKB base (`eeab422`) to enforce safety rule S8 (nothing an AE64 receives may change, byte for byte). Each JSON file stores the full 64-byte outgoing frames as hex strings (with only the periodic active-profile poll `02 03 01` dropped via `isProfilePoll`). To record or re-record before MKB work starts, run `AE64_GOLDEN_RECORD=1 npx vitest run tests/golden-ae64.test.ts` (in PowerShell: `$env:AE64_GOLDEN_RECORD='1'; npx vitest run tests/golden-ae64.test.ts; Remove-Item Env:AE64_GOLDEN_RECORD`). Once MKB changes begin, these fixtures must never be re-recorded or edited.
